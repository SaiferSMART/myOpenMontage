🏆 Топ-5 «брать в работу первыми» (всё едет на твоей машине, без GPU)

#ПайплайнЧто даёт тебе
1clip-factoryЭфир → пачка коротких клипов для Shorts/Reels с хуками и субтитрами. Прямое попадание в твой контур.
2talking-headДоводка записей с лицом: транскрипт, правки, русские «тикток-субтитры» по словам.
3hybridПромо: куски эфира + титры/графика + диктор ElevenLabs.
4animated-explainerАнонсы/промо без лица — графика + твой TTS.
5localization-dubРусские субтитры/дубляж своих роликов (без lip-sync — он требует GPU).

🚫 Что НЕ поедет (и не тратить время)

Всё с пометкой GPU: локальная генерация видео, lip-sync, апскейл, ComfyUI — без NVIDIA-карты бессмысленно. Аватары HeyGen — платный сервис, не твой профиль. CLIP-поиск по видеокорпусу — на CPU мучительно.

💡 Идеи-жемчужины (переносим методом, не кодом)

ИдеяСуть
Locked scriptФинальный дикторский текст «замораживается» отдельно от раскадровки — голос не плывёт от правок картинки.
Дикторский текст~2,5 слова/сек, числа писать «как произносить», хук за первые 3 секунды, структура Hook→Story→Proof→CTA.
Русские субтитры⚠️ Не брать Whisper-модели с «.en» — они ПЕРЕВОДЯТ, а не транскрибируют. Всегда language=ru. Группировка слов по энергии, позиции с учётом UI платформ.
House styleПалитра+шрифты+тема объявляются ДО вёрстки; анти-шаблон «AI-дефолтов» (неоновые градиенты и т.п.).
Каталог текст-эффектов5–7 именованных эффектов титров под бренд вместо изобретания каждый раз.
Аудио→анимацияПререндер RMS/FFT из трека в JSON → пульсация графики под музыку без генеративного видео.

🗺️ Порядок внедрения (когда решишь пробовать)

1. Поднять демо Remotion (без ключей) — проверка машины.
2. Прогнать один свой эфир: транскрипт ru → субтитры → 1–3 шортса (clip-factory).
3. Собрать одно промо hybrid с ElevenLabs.
4. Зафиксировать свой house style + 2 плейбука (flat — IG, clean — YouTube).
Нужно на машине: Python 3.10+, ffmpeg (есть), Node 18+ (для кинетики HyperFrames — 22+). Ключи: ElevenLabs уже есть; сток Pexels/Pixabay — бесплатные.
